# Exercícios de JavaScript

Repositório com os meus exercícios de JavaScript, organizados por assunto. Faz parte da minha jornada de estudos em programação e em QA (Quality Assurance).

## O que tem aqui

- Variáveis e tipos de dados
- Lógica de programação
- Funções construtoras
- Exercícios numerados, de 01 a 09

## Como executar

É preciso ter o [Node.js](https://nodejs.org) instalado. Em um terminal, dentro da pasta do exercício, rode:

```
node nome-do-arquivo.js
```

Os exercícios que usam HTML podem ser abertos direto no navegador.

## Objetivo

Praticar a base da linguagem para, mais adiante, escrever testes automatizados.
